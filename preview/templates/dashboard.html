How It Works

competitors.yaml

competitors:
  - username: "nike"
  - username: "adidas"
  - username: "puma"

months_back: 6
output_dir: "./output"

Run Command

yourcoverage --config competitors.yaml

Output

output/
├── competitor_report_2026-03-24.csv
├── competitor_report_2026-03-24.json
└── errors_2026-03-24.log  (if any)

CLI Options

--config PATH    Config file (default: competitors.yaml)
--months N       Override months back
--output PATH    Override output directory
--format         csv | json | both
--verbose        Enable debug logging

Metrics Per Month

• post_count       — Total posts published
• total_likes      — Sum of all likes
• total_comments   — Sum of all comments
• avg_likes        — Average likes per post
• avg_comments     — Average comments per post
• engagement_rate  — (likes + comments) / (posts × followers)
• follower_count   — Current snapshot
